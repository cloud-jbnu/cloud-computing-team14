# web — 컴퍼스 프론트엔드

컴퓨터 전공 학생을 위한 정보 모아보기 웹.

- 카테고리: 대학 소식 / 공모전·대회 / 취업·인턴 / 테크 트렌드(GitHub·최신기술·이슈)
- 분야 필터: 백엔드, 프론트엔드, AI, 데이터, 클라우드, 네트워크, 보안, 모바일 (여러 개 선택 가능)
- 검색, 최신순·마감임박순 정렬, 북마크(브라우저 저장), 마감 임박·GitHub 트렌딩 사이드 패널
- 상단 탭 세부 메뉴: 데스크톱에서 카테고리 탭에 마우스를 올리면(키보드는 Tab으로 들어가면) 해커톤·공모전 같은 세부 구분이 글 수, 가장 가까운 마감과 함께 열림. 고르면 그 카테고리로 가서 해당 칩이 골라짐. 휴대폰에서는 탭을 누르면 바로 이동하고 칩으로 고름
- 전체 탭: 맨 위에 마감 가까운 글 4개를 카드로, 내 학교를 정했으면 그 학교 새 공지를 따로 보여 줌. GitHub 저장소는 오른쪽 "오늘의 GitHub"에만 나오고 목록에서는 빠짐 (검색하면 나옴)

## 실행

```bash
python -m http.server 8765 --directory web
```
→ http://localhost:8765

## 구조

```
index.html      화면 뼈대
css/style.css   스타일 (기본 밝은 화면, 헤더 버튼으로 어두운 화면 전환)
js/data.js      카테고리·분야 정의 + 예시 데이터
js/api.js       데이터 접근 (API_BASE 비어 있으면 예시 데이터 사용) + 주소 설정
js/auth.js      로그인 (Cognito: 디스코드는 PKCE, 이메일은 Cognito API 직접 호출)
js/app.js       라우팅(#all #univ #contest #jobs #tech #saved), 필터, 렌더링
js/chat.js      챗봇 창 (오른쪽 아래 "AI에게 물어보기")
```

CSS·JS를 고치면 `index.html`에서 해당 파일 주소 끝의 `?v=2` 숫자를 하나 올려 주세요. 그래야 브라우저가 예전 파일을 캐시에서 꺼내 쓰지 않고 새 파일을 받아요 (안 올리면 새 HTML과 예전 CSS가 섞여 화면이 깨질 수 있음).

## 내 학교

처음 들어오면 "어느 학교 학생이세요?" 창이 한 번 뜹니다. 피드 제목 아래 **바꾸기**로 언제든 바꿀 수 있습니다.

- 학교를 고르면 **전체** 탭·마감 임박·탭 숫자에서 다른 학교 공지를 빼고, **대학 소식** 탭은 내 학교 칩이 골라진 채로 열립니다 (전체 칩을 누르면 모든 학교).
- "목록에 없는 학교"로 정하면 전체 탭에서 학교 공지를 모두 빼고, 다니는 학교 이름을 남길 수 있습니다 (학교 추가할 때 참고).
- 공모전·채용·테크 글은 학교와 상관없이 다 보입니다. 북마크도 그대로 보입니다.
- 브라우저에 저장하고, 로그인하면 서버(`/me/profile`)에도 저장해 다른 기기에서도 같게 씁니다. 디스코드 키워드 알림과 챗봇도 이 설정을 씁니다.

## 챗봇

오른쪽 아래 **AI에게 물어보기**를 누르면 대화 창이 열립니다. "이번 주에 마감하는 대회 알려줘"처럼 물으면 서버(`POST /chat`)가 모아 둔 글에서 골라 Gemini로 답하고, 고른 글을 카드로 함께 보여 줍니다. 카드를 누르면 원문이 새 탭에서 열립니다.

- 모아 둔 글에 없는 것(예: "하버드대 해커톤 알려줘")을 물으면 Google 검색으로 찾은 답을 "웹 검색 결과" 칸에 따로 보여 줍니다. 출처 링크와 Google 검색 추천이 함께 나옵니다. 웹 검색은 사용자당 하루 5번까지이고, 넘으면 모아 둔 글로만 답합니다.
- 로그인한 사용자만 쓸 수 있습니다 (이메일·디스코드 모두). 하루 30번까지이고, 남은 횟수가 입력칸 아래에 나옵니다.
- 앞선 대화 6개까지 같이 보내서 "그 중에 온라인인 건?" 같은 이어지는 질문도 됩니다. 대화는 페이지를 열어 둔 동안만 기억하고, 로그아웃하면 지웁니다.
- 로그인 설정 값이 비어 있으면 창에 안내 문구만 나옵니다.

## 로그인 · 키워드 알림

오른쪽 위 **로그인**을 누르면 로그인 창이 열립니다. 이메일·비밀번호로 로그인하거나, **이메일로 회원가입**(메일로 온 6자리 인증 코드 입력 → 자동 로그인), **디스코드로 로그인** 중에서 고를 수 있습니다. 비밀번호를 잊었으면 같은 창에서 메일 인증 코드로 바꿉니다.

키워드 알림은 디스코드 DM으로 보내므로, 디스코드로 로그인한 경우에만 오른쪽 "키워드 알림"에서 구독 키워드를 추가·삭제할 수 있습니다. 이메일로 로그인하면 그 자리에 디스코드 로그인 안내가 나옵니다. 북마크는 로그인과 상관없이 브라우저에 저장됩니다.

`js/api.js` 맨 위의 `API_BASE`, `AUTH_BASE`, `AUTH_CLIENT_ID` 세 값을 모두 넣어야 켜집니다. 값은 배포 후 Outputs에 나옵니다 ([infra/README.md](../infra/README.md)). 비어 있으면 로그인 버튼을 눌렀을 때 안내 문구만 나옵니다.

로그인 후 돌아오는 주소는 `http://localhost:8765/`로 등록돼 있으므로, 로컬에서는 꼭 이 포트로 열어야 합니다.

## 백엔드 연결

`js/api.js`의 `API_BASE`에 API 주소를 넣으면 `GET {API_BASE}/items`에서 `{ "items": [...] }`를 받아옵니다.

```json
{
  "id": "c2",
  "category": "contest",          // univ | contest | jobs | tech
  "subtype": "CTF",               // 학교명, 대회 종류, 채용 형태, GitHub/최신기술/이슈
  "source": "정보보호 동아리 연합",
  "title": "화이트햇 CTF 2026 예선 참가 접수",
  "fields": ["security", "network"],
  "date": "2026-11-09",
  "deadline": "2026-11-18",       // 선택
  "url": "https://...",
  "repo": { "lang": "Go", "starsToday": 412 }   // GitHub 항목만
}
```

Item에 `summary`(AI 요약, 문자열 배열)가 있으면 `app.js`의 `itemHTML`이 제목 아래에 한 줄씩 보여 줍니다. 요약은 크롤러가 글을 저장할 때 만들어 붙이며, 없는 글은 제목만 나옵니다.
